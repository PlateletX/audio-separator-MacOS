## ✨ 功能特性

- **离线运行**：模型文件已内置于根目录，无需连接 Hugging Face 或下载额外权重。
- **自定义参数**：支持在 GUI 界面手动调整以下核心参数以优化分离质量：
  - `Overlap` (重叠度)：调整片段衔接的平滑度。
  - `Segment Size` (片段长度)：根据显存大小调整处理粒度。
  - `Batch Size` (批处理次数)：控制推理并行效率。
- **多格式输出**：支持导出为 WAV, FLAC, MP3 等多种主流音频格式。
- **GPU 加速**：原生支持 ONNX Runtime CUDA 加速（需安装相关驱动）。
